# Le Fil Rose 🎀

A little space to bring your days together.

Le Fil Rose is a personal productivity website designed to make planning, focusing, and staying organized feel easier and prettier. It brings together beautiful design and practical tools to help you make the most of your time.
The goal is simple: make productivity feel less overwhelming and more intentional.

✧ Features

* Daily Inspiration
* Task Management — Organize tasks into three stages: Not Started, In Progress, and Completed.
* Calendar — Plan your schedule with monthly, weekly, and daily views.
* Pomodoro Timer — Focus in timed sessions with customizable work periods and breaks.
* Focus Tracking — Keep track of the time you spend working toward your goals.

✧ Built With

* HTML
* CSS
* JavaScript

✧ Getting Started

You can access the website through its published GitHub Pages link.

To run it locally:

1. Clone or download this repository.
2. Open index.html in your browser.
